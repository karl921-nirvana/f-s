# Flower & Sea Trading 官方网站

## 项目结构

```
f-s/
├── index.html              # 主页
├── README.md               # 项目说明（本文件）
├── css/
│   └── (共用样式文件)
├── js/
│   └── (共用脚本文件)
├── images/
│   └── (产品图片、视频等资源)
```

## 快速开始

1. **本地预览**：
   - 直接在浏览器中打开 `index.html`
   - 或用 Python 启动本地服务器：
     ```bash
     python -m http.server 8000
     ```
   - 然后访问 http://localhost:8000

2. **编辑内容**：
   - 用任何文本编辑器打开 `index.html`
   - 修改文案、添加图片、调整样式

3. **添加图片**：
   - 将图片放在 `images/` 文件夹
   - 在 HTML 中引用：`<img src="images/product.jpg">`
